# Trilha Acquia Back End Specialist

Curso de preparação para a certificação Acquia Certified Back End Specialist (Drupal 10/11), em página única e estática: seis módulos com aula escrita, laboratório prático e simulado cronometrado no formato da prova (60 questões / 120 min / 70%).

**Site:** https://lucas-cunico.github.io/acquia-be-specialist/

O progresso (blocos estudados e melhor nota de cada simulado) fica no `localStorage` do navegador — nada é enviado a servidor algum.

## Editar

Todo o conteúdo, estilo e comportamento vivem em `index.html`, sem dependência externa. Abra o arquivo direto no navegador para testar.

## Publicar

```
git push origin main            # fonte
git push origin main:gh-pages   # publica
```

GitHub Pages serve a branch `gh-pages` a partir da raiz.
